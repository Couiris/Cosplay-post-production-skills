# 大合成华丽特效库

默认选一个主特效、一个环境特效和一个空间层次特效。每个特效拆成 near / subject-plane / far 三个深度片段，并写核心亮度、边缘衰减、体积、遮挡、风向、光照可达面、投影/反射与景深。

每个特效必须输出 `anti_sticker_contract` 与 `anti_sticker_validation`：近中远片段不可共享同一锐度/透明度；与人物、武器、衣摆、地面、雾尘的交界必须有真实遮挡或介质反应；边缘亮度、色散、运动模糊和颗粒随深度变化。平面符文也要服从承载面透视、起伏、粗糙度和遮挡，禁止剪贴画边缘、均匀外发光和无接触悬浮。

发光特效遵守 [人物原光反推与环境光源重建](lighting-reconstruction.md)：默认是次级光源，不取代冻结的环境主光；只要可见发光，就必须建立 `vfx_relight_mask` 对人物可达局部做相应染色；强自发光还必须定义亮度响应、距离衰减、遮挡终止、反射和对应投影。染色保留人物身份、结构、肤色基准和材质纹理。

## 元素系

- 火：火舌、余烬、热浪、烟柱、熔蚀、地面反光；变体为圣火、蓝焰、黑焰、熔岩。
- 冰：霜纹、冰晶、冻雾、冰锥、冻结蔓延、折射与焦散。
- 雷：主电弧、分枝、节点爆光、电离雾、地面灼痕；避免均匀描边。
- 水：水带、漩涡、飞沫、浪墙、湿润反射、焦散；接触处需涟漪或水压反应。
- 风：气流带、风刃、尘环、叶/纸/飘带；所有运动线索统一方向。
- 土/岩：碎石、岩柱、尘浪、裂地、晶矿；悬浮物写重力失效依据和投影。
- 植物：藤蔓生长、花开、根系、孢子、花粉；生长必须沿表面附着。
- 光/暗：圣光、暗雾、影触手、领域边界；光有入口和遮挡，暗不简单压黑人物。

## 魔法与神性

- 法阵：贴地、竖直、球形、多层同心；沿地面单应性/人物朝向，符号在低置信度时用抽象几何。
- 符文环：环绕手、武器、身体或空间；前后遮挡与景深分离。
- 护盾：球面/弧面折射、冲击波纹、边缘亮度；不能像平面圆贴纸。
- 传送门：内部景深、边缘能量、环境溢光、地面反射与遮挡。
- 翅膀：羽翼、机械翼、能量翼、骨翼；根部结构、展开尺度、投影和世界观依据必填。
- 召唤/灵体：半透明体积、内部层次、投影或缺少投影的物理理由。

## 科技与宇宙

- 全息界面、扫描束、数据流、无人机群、能量核心、机械展开、故障像素、引力扭曲、星尘、流星、空间裂隙。
- 科技效果用线宽、刷新层、透明膜、色散和受环境反射定义；避免全画面同色霓虹。

## 战斗与破坏

- 冲击波、爆炸、碎片、火星、烟尘、裂纹、弹道、武器拖尾、冻结/熔蚀传播。
- 写起点、传播方向、速度、受影响材质和前后时序；爆炸核心、火球、烟柱与飞散碎片不能处于矛盾阶段。

## 空间层次

- 空气透视、体积光、前景遮挡、雾带、粒子簇、散景光点、雨雪、灰烬、花瓣、羽毛、水滴、气泡。
- 粒子不是均匀噪点：近处大且可能虚，中部较清晰，远处小而淡；脸周围保留干净区。

## 0–100 控制

- `vfx_intensity`：单个特效能量与视觉冲击。
- `effect_density`：特效种类与实例数量。
- `effect_scale`：主特效的空间尺度。
- `emission_strength`：自发光核心与溢光。
- `particle_density`：粒子数量。
- `vfx_glamour_level`：综合华丽度，只作为以上参数的联动入口。

任何参数都不得改变人物变换、画布、相机、世界观或锁定像素。高华丽度优先扩大空间层次和叙事关联，不优先把脸周围塞满粒子。
