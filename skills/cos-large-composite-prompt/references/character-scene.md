# 角色与场景决策

## 角色世界观卡

记录：作品/世界观、角色、时代与地域、种族/组织/阵营、职业与社会身份、能力体系、生活方式、常驻地点、代表颜色/材质/形状、剧情时刻、用户明示/可见证据/外部资料、置信度。

未知项写未知。用户明示 > 可核实设定 > 原片服装/道具强线索 > 中性兼容推断。不得凭低置信度生成专属纹章、宗教标志、阵营武器或具体剧情遗物。

## 场景选择

1. 一个主世界：决定建筑、地表、技术层级、天气和主材质。
2. 一个主视觉：如神殿、巨兽、飞船、能量核心、瀑布或城市天际线。
3. 最多两个辅助母题：一个负责角色叙事，一个负责空间层次。
4. 一个主材质、一个对比材质、一个点缀材质；一个呼应角色的颜色、一个低饱和环境色、一个克制发光色。
5. 性格决定节奏：克制/疏离用秩序和留白；活泼用有方向的散点；威严用轴线和大体块；神秘用遮挡和受控暗部。

## 道具准入

每个道具必须包含：

- `worldbuilding_basis`：对应时代、地域、组织、职业、能力或剧情时刻。
- `function`：人物为什么可能使用或接近它。
- `evidence/confidence`：用户明示、高/中/低置信度。
- `technology_and_material_fit`：制造工艺和材质是否属于该世界。
- `story_value`：引导视线、解释地点、提供尺度或强化情绪；没有作用则删除。

时代错位只有用户明确要求混搭时才允许，并要说明叙事理由。
