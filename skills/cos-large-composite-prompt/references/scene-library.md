# 大合成场景素材库

选一个主世界、一个主地标、最多两个辅助母题。每件素材补全世界观依据、人物尺度、透视、材质、焦平面距离、虚化和光影。表中为五层候选，不整行照搬。

## 东方幻想

- 天宫云海：云台/镜面水；飘带/玉栏；天门/祭坛；宫阙群/山峰/巨像；圣光/羽毛/金尘。
- 仙侠山门：石阶/阵纹；松枝/剑碑；山门/悬浮剑阵；群山/瀑布/云海；剑气/雾/符文。
- 江南夜雨：湿石/河埠；伞边/芭蕉；乌篷船/石桥；白墙黛瓦/水巷；雨丝/水汽/灯尘。
- 敦煌神域：砂岩/织毯；经幡/陶器；壁画洞窟/乐台；风蚀城/沙海；金尘/飘带/圣光。
- 妖都夜行：湿石/符纹；纸灯/绳结；鸟居群/市集；山城/巨月；蓝火/御札/妖雾。
- 龙宫海境：珊瑚沙/镜面水；海草/贝壳；珍珠台/宫门；海底宫殿/深海峡谷；气泡/鱼群/焦散。

## 西方幻想

- 哥特圣堂：石砖/长毯；荆棘/烛台；圣器台/祈祷凳；尖塔/彩窗/巨像；烛烟/黑羽/光束。
- 王城宫殿：大理石/红毯；帷幔/雕花栏；王座/乐台；柱廊/高窗/城堡；金尘/花瓣/旗帜。
- 魔法学院：阵纹石地；浮书/羽毛笔；讲台/星图仪；塔楼/拱廊/天文穹顶；符文/光尘/猫头鹰远影。
- 黑暗城堡：裂石/灰烬；锁链/破旗；王座/盔甲架；残塔/雷云/深渊；暗雾/余烬/蝙蝠。
- 精灵圣林：苔地/溪流；花枝/晶簇；古树/祭坛；林冠/瀑布/雾谷；孢子/萤火/花粉。
- 龙巢宝库：岩地/金币散点；骨刺/锁链；龙蛋/宝箱；洞窟/巨龙；烟/火星/尘金。
- 冰晶王国：冰面/霜纹；冰柱/晶枝；镜面阶梯/冰座；冰塔/雪山；冻雾/雪晶/折射光。
- 浮岛遗迹：草岩断面；藤蔓/碎石；断桥/遗迹柱；云海/远岛/瀑布；飞鸟/云雾/漂浮石。

- 太空舰桥：金属地台；设备臂/舱窗；控制台/座椅；星海/行星/舰体；扫描点/冷凝雾/微粒。
- 轨道空间站：舱板/磁轨；机械臂；气闸/运输舱；地球/太阳翼/站体；星尘/姿态喷流。
- 生化实验室：树脂地坪；器皿/线缆；培养舱/机械臂；模块墙/观察窗；冷雾/扫描束/警示光。
- 机械工厂：油污钢板；链条/管线；传送带/机械臂；高炉/梁架；火花/蒸汽/金属尘。
- 全息竞技场：发光地格；护栏/屏边；浮空平台/记分装置；穹顶/观众体块；扫描线/数据碎片。
- 末日都市：龟裂路/锈水；钢筋/破布；废车/路障；坍塌楼群/烟柱；灰/火星/风尘。
- 地下避难所：混凝土/导向线；电缆/门框；补给架/终端；厚门/管廊；冷雾/警示灯尘。
- 晶体星球：矿化地表；晶枝/漂浮石；巨晶/遗迹；异星山脉/行星环；星尘/能量流。
- 数据虚空：反光黑台；线框/代码片；核心/悬浮面板；网格塔/无穷空间；像素粒子/故障光。

## 材质与素材族

- 建筑：斗拱/飞檐/月洞门/鸟居/尖拱/柱廊/城垛/玻璃幕墙/舱门/模块墙/能源核心。
- 地表：砖/石/木/地毯/泥/沙/草/苔/雪/冰/浅水/金属/树脂/灰烬/熔岩。
- 道具：书卷/仪器/家具/餐具/兵器架/盾/旗/终端/机械臂/载具/祭坛/王座/行李。
- 植物生物：竹/松/枫/樱/藤/蕨/菌类/花海/鸟/蝶/鱼/龙/巨狼/机械兽/神鸟。
- 空气：尘/雾/烟/雨/雪/花瓣/灰/火星/金粉/星尘/冰晶/水滴/气泡/数据碎片。

每个材质写基色、粗糙度、微纹理、接缝、边缘、磨损/洁净、湿度、透明/反射；每个大型对象写人物尺度参照、落点、重量感、遮挡与投影。
