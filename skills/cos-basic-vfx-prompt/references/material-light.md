# 特效材质与光影

每次写 `material_emission / relight_and_blend / anti_sticker` 时读取。目标只有一个：**让特效像在拍摄现场真实发生、被同一台相机拍到，而不是后期贴上去的 PNG。**

## 1. 特效的五层物理描述

任何特效都按这五层写，缺层就会像贴片：

1. **核心（core）**：最亮/最密的能量中心——颜色、亮度、是否过曝、形态（焰心、电弧节点、阵眼、能量核）。
2. **体（volume/body）**：火焰的火舌、水流的水带、雾的体积、光束的柱体——厚度、透明度梯度、内部湍流/纹理、运动方向与速度感。
3. **边缘衰减（falloff）**：向四周如何消散——羽化宽度、颜色如何从主色过渡到环境色、粒子如何变稀变淡。禁止硬边剪贴轮廓与等宽外发光描边。
4. **交互（interaction）**：对人物的局部染色、对地面/墙面/水面/金属/湿面的反射与投影、穿过雾尘时的体积散射、接触处的涟漪/焦痕/霜结/压尘。
5. **成像匹配（capture match）**：按所在景深决定锐度与散景、运动方向上的快门拖影、与原片一致的颗粒和曝光滚降；强发光只在镜头方向正对时允许轻微眩光。

## 2. 能量/特效材质族

写 `material_emission` 时从对应材质族取词，至少写清「基色 + 核心亮度 + 边缘衰减 + 体积/透明 + 颗粒尺度」。

| 材质族 | 关键描述词（写法要点） | 典型反例（禁止） |
|---|---|---|
| 火焰/焰体 | 多层焰心（白热→主色→烟色）、火舌翻卷湍流、上升加速、热浪折射空气、余烬颗粒上飘、底部接触处最亮 | 一片均匀橙红渐变、无核心无湍流、火舌向下 |
| 冷焰/灵火 | 低饱和青蓝/苍白、焰体半透明、无热浪或反向冷雾、颗粒细 | 把橙火直接改色相 |
| 冰霜 | 六出结晶结构、生长纹路、半透明带折射与内部焦散、表面冷高光、边缘霜花毛化、冻结沿表面蔓延 | 白色不透明糊一片、霜像贴纸没有厚度 |
| 雷电 | 主干电弧 + 分叉枝、节点爆光、电离空气微光、瞬时跳跃感、沿导体/表面优先走形、边缘色散 | 均匀发光曲线描边、电弧没有分叉和节点 |
| 水体 | 体积透明、菲涅尔边缘亮、内部焦散光斑、表面张力形态、飞溅水滴大小分级、湿润面反光 | 蓝色塑料带、水滴全一样大 |
| 气流/风 | 半透明丝带状折射率变化、带动尘/叶/水雾等可见载体、方向统一、压缩与拖尾 | 凭空画白色弧线、没有被吹动的载体 |
| 岩土 | 受光面/背光面、碎石棱角与磨损、悬浮需写反重力依据与投影、落地有压尘 | 石头无重量感、悬浮无投影 |
| 植物生长 | 沿承载表面攀附、生长方向有顶端优势、叶脉/花瓣透光、根部附着 | 藤蔓悬空穿墙、花瓣不透光 |
| 圣光/光束 | 体积光（丁达尔）、需要光源入口与遮挡体、光内尘雾可见、边缘随介质浓度变化 | 没有入口的凭空光柱、均匀白色三角 |
| 暗影/黑雾 | 吸光而非发光、内部微弱冷色/紫点光、翻涌体积、边缘吞光过渡、不能简单把人物压黑 | 纯黑色块、黑雾反而发亮 |
| 符文/法阵 | 线条自发光 + 笔画点燃顺序、贴服从承载面起伏与透视、能量在线槽内流动、符文学置信度低时用抽象几何 | 平面正圆贴图、符文是乱码、法阵不跟地面透视 |
| 护盾/结界 | 弧面/球面折射、菲涅尔边缘亮中心透、受击处波纹、厚度感与后方扭曲 | 正圆平面片、均匀透明度 |
| 全息/科技光 | 线宽一致的扫描线/刷新层、半透明膜、边缘色散、投影在实体表面、偶发扫描带与故障跳帧 | 全屏同色霓虹、全息投影不透明 |
| 粒子/光尘 | 大小分三级（近大远小）、亮度有亮灭节奏、密度在空间中成簇而非均匀噪点、脸周留净区 | 全屏均匀撒点、粒子全同尺寸同亮度 |
| 烟/雾/蒸汽 | 体积浓度梯度、受光面带色背光面灰、随气流缓慢翻滚、与光源相交处可见光路 | 灰色实棉团、边缘刀切 |
| 玻璃/冰晶碎裂 | 厚度折射、棱角色散、裂纹走向有受力点、碎片大小分级与运动模糊 | 白色裂纹线、碎片无折射 |

## 3. 发光特效对人物的染色（vfx_relight_mask）

只要特效可见发光，就必须给人物一个「物理上说得通」的局部光响应，否则必然假。按以下规则写：

- **可达性**：只染「朝向光源 + 中间无遮挡 + 在有效距离内」的表面。掌心火球染手掌、指缝、下颌底面与同侧衣襟；身后法阵只染轮廓边和发丝；被身体挡住的另一侧不亮。
- **颜色**：取特效主色，低饱和叠加在肤色上（肤色区尤其克制，保留肤色基准，不把脸染成纯蓝/纯红）。
- **强度与衰减**：亮度变化随距离平方衰减的观感——贴身强、两步外弱；写「最大亮度变化不超过一档」级别，强自发光才允许轮廓高光接近过曝。
- **表面差异**：金属甲片/武器出锐利点状高光；布料出柔和漫反射染色；发丝出边缘透光；湿润皮肤/眼睛可有小高光点；哑光织物只吃很弱的环境色。
- **遮挡终止**：手挡住火，手背亮、手心侧暗；衣褶凹槽里光进不去；模型不得把被遮挡面也染亮。
- **投影方向**：特效作为光源时，人物/道具投向邻近表面的影子方向必须背离特效位置，且与原片主光投影不矛盾（特效光通常是弱次级光，影子淡而短）。
- 反过来，**强发光却对人物和环境零反馈**、以及**无来源把整个人物均匀灌色**，两者都判失败。

## 4. 特效与原片光源的关系（默认次级光原则）

- 先按 lock-contracts.md 第 4 节冻结 `subject_light_profile`；特效光是 `secondary_emissive`，不取代主光。
- 特效颜色与原片冷暖冲突时（如冷调夜景里的暖火），保留对比但缩小染色面积；和谐时（同色系魔法）可略扩大溢光范围。
- 可见灯具、窗、屏幕、霓虹是最高优先级证据：特效光不能和它们打架（不能在画面左侧已有强蓝光时让右侧特效在人物左脸投出更强的右侧光）。
- 镜头眩光/光晕只允许出现在「特效位于镜头与人物之间或逆光方向、且强度足够」时，形状匹配原片镜头语言；原片没有眩光风格就不加。

## 5. 景深、遮挡与运动（让特效进入相机空间）

- **先锁焦平面**：人物眼睛/面部（或原片实际焦点）所在深度为基准。
  - 与人物同平面的特效（掌心、胸前、手中武器）锐度接近人物；
  - 身后特效随距离渐软、对比饱和渐降；
  - 前景穿越层（飘过镜头的花瓣/雪/雾）明显虚化、可能带快门拖影；
  - 贴地特效（法阵/霜面/水洼）近缘清楚、远缘随地面没入景深。
- **遮挡优先于发光**：特效被身体、头发、武器、背景物遮挡时，遮挡部分必须消失在轮廓后，不允许「光透过来把人物边缘描一圈」当遮挡；只有逆光轮廓光允许沿发丝边缘透光。
- **运动一致性**：一张照片是一个瞬间。火焰倾斜、雨丝方向、飘带走势、粒子拖尾、衣摆被气流带动的暗示全部统一一个风向/动势；禁止同一画面里火往左、烟往右、粒子静止。
- **时序唯一**：静态图只表现一个阶段（蓄力 XOR 爆发 XOR 余烬），需要连续阶段时输出多张预设分别使用。

## 6. anti_sticker 反贴片合同（每个特效必填）

每个特效在 `anti_sticker` 里针对其类型写 2–4 条最易翻车点与规避。通用七项：

1. **体积/厚度**：不是平面图形——护盾有球面、法阵有悬浮高度与厚度、火焰有数层焰体。
2. **前后穿插**：与人物/武器/衣摆/地面有真实遮挡和压叠关系。
3. **边缘衰减**：亮度与不透明度向边缘渐变，无等宽描边、无剪刀轮廓。
4. **局部染色**：在人物可达面有同色克制光响应。
5. **投影/反射**：承载面有接触影、辉光反射或介质反应（焦痕/湿痕/霜结/涟漪/扬尘）。
6. **介质反应**：穿过空气尘雾时照亮介质；在水面/金属/湿地面有对应反射；在布料上沿褶皱起伏。
7. **颗粒与景深匹配**：同深度同锐度趋势、同颗粒、同曝光滚降；远景不比原片清晰。

## 7. 四种渲染风格的措辞（默认 CG，其余按用户要求覆盖）

- **CG 游戏过场（默认）**：「以高精度 3D 渲染呈现，表面细腻、边缘清晰锐利，光效具体积感与全局光照，类似高端游戏过场 CG 的技能特效；能量核心高亮、外层半透明衰减，带细密能量粒子」。
- **写实电影 VFX**：「真实电影特效质感，流体与粒子遵循物理，光比克制，烟雾与热浪真实，摄影曝光自然，无 3D 建模塑料感」。
- **国风仙侠电影**：「国风仙侠电影质感，灵力光晕通透，能量呈写意流转的光带与符纹，色彩取金青/青白/赤金国风色，光粒细碎，氛围缥缈大气」。
- **二次元手绘**：「赛璐璐/厚涂手绘质感，干净线条、平涂加柔和渐变光，高光形状明确，弱化写实质感」。
- **扁平极简**：「简约平面光效，柔和渐变无强体积，低对比，适合清新极简画面」。

## 8. 强度三档通用措辞

| 档位 | 数值 | 特效本体 | 光交互 | 密度/尺度 |
|---|---|---|---|---|
| 轻 | 0–33 | 淡淡、若隐若现、边缘柔和 | 几乎不改变原光影，仅贴身微弱染色 | 稀疏、小尺度、留大量负空间 |
| 中 | 34–66（默认 60） | 清晰可辨、形态完整、层次分明 | 与人物有自然局部光交互与承载面反射 | 中等密度，主特效完整、辅点到为止 |
| 强 | 67–100 | 炽烈/汹涌、核心接近过曝、体积饱满 | 明显照亮人物受光侧与邻近环境，投影可辨 | 大尺度、多层粒子，但脸周仍留净区 |

强度升高时优先扩大体积与纵深层次，而不是等比加亮到全图过曝，也不是把粒子铺满人物面部。
