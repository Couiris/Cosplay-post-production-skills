# 新增打光与溶图

用户提出“重新打光/补一盏灯/加轮廓光/投影光纹/溶图/把两张图融合”时读取。本文件只处理保留底图主体、姿态、机位和大部分场景的增量编辑；供体图成为新背景或需要重摆人物时转半合成/大合成。

## 1. 三种光影模块的边界

- `lighting_reshape`：不新增明确光源，只优化已有明暗、提亮脸、压高光、增强轮廓与层次。
- `virtual_lighting_plan`：新增一盏或一组可定位、可解释的虚拟灯，包括主光、辅光、轮廓光、地灯、窗光、霓虹、投影光纹和画外灯。
- `vfx_plan.effects[].vfx_relight_mask`：只描述某个自发光特效对邻近表面的次级影响，不承担全场打光。

同一预设可以同时启用，但必须写清主次：原片主光、虚拟灯、特效光三者不能互相反转。默认最多新增 1 个主导虚拟灯 + 1 个弱辅光/轮廓灯。

## 2. virtual_lighting_plan

除五段式外，`change` 至少包含：

```json
{
  "lighting_goal": "人物与场景的目标光感",
  "preserve_base_exposure": true,
  "lights": [
    {
      "light_id": "key_1",
      "role": "key | fill | rim | practical | gobo | bounce | underlight",
      "motivation": "可见窗/灯/霓虹/火源，或明确的画外摄影灯",
      "source_position": "相对相机与人物的位置",
      "direction_and_elevation": "方向与高度",
      "color": "色温或色相",
      "hardness": "hard | semi_soft | soft",
      "spread": "光束范围与边缘衰减",
      "intensity": 50,
      "distance_falloff": "随距离衰减方式",
      "affected_surfaces": ["可达面"],
      "shadow_behavior": "投影方向、软硬和遮挡",
      "exclude": ["禁止受光区域"]
    }
  ]
}
```

### 常用灯型

- 电影侧逆光：画外后侧上方半软光，描亮发丝、肩线、披风外沿；不在脸正面制造第二鼻影。
- 柔和窗光：来自可见窗或画外窗方向的大面积软光，亮面宽、阴影过渡长，色温服从环境。
- 霓虹双色：一侧青、一侧洋红的弱色光，只染朝向灯源的边缘和反射材质，肤色中部保持中性。
- 火光：低位暖橙、轻微不均匀亮度与柔软跳动观感；静态图只选一个亮度相位。
- 月光：高位偏冷方向光，亮度克制，暗部仍保留原环境填充，不把夜景打成白天。
- Gobo 投影：树影、百叶窗、花窗、圆形聚光等投影必须沿人物和墙地折角连续变形。
- 舞台追光：光锥起点、方向和截面一致，空气中只有存在雾尘时才显示体积光路。

### 打光验收

- 每盏灯能指出来源或明确是画外灯。
- 人物和背景同一光路上的受光、遮挡、投影一致。
- 亮面不剪切、暗部不死黑、肤色不被全身染色。
- 不制造互相矛盾的鼻影、下颌影、地面投影或多重轮廓边。
- 失败只重试该灯的 `affected_surfaces` 与投影区。

## 3. image_blend_plan（溶图）

“溶图”按多图局部合成理解，不等同于 Photoshop 的随机像素 `Dissolve` 混合模式。必须先确定：

- `base_image`：保留构图、人物、姿态、机位和画布的底图。
- `donor_images[]`：每张供体图只提供指定内容。
- `transfer_only`：要迁移的对象、纹理、光效、天空、前景、图案或局部环境。
- `do_not_transfer`：供体人物、脸、姿态、文字、水印、背景或无关色调等禁止带入内容。

除五段式外，`change` 至少包含：

```json
{
  "base_image": "input_1",
  "donor_images": [
    {
      "ref": "input_2",
      "transfer_only": ["指定内容"],
      "do_not_transfer": ["供体图无关内容"]
    }
  ],
  "alignment": "按地平线/灭点/物体特征/人物锚点对齐",
  "blend_method": "masked_normal | screen_lighten | multiply_dark | soft_light_texture | depth_aware_composite",
  "opacity_or_strength": 55,
  "transition_zone": "蒙版边界与羽化范围",
  "color_harmonization": "供体向底图匹配，不反向破坏底图身份基准",
  "depth_and_occlusion": "供体进入哪一深度层、被谁遮挡",
  "seam_healing": "边缘、接缝、重影和色边处理"
}
```

### 混合方式选择

- 实体/服装/道具：`masked_normal` 或 `depth_aware_composite`，必须保留实体遮挡、接触影和材质。
- 发光、火花、光束：`screen_lighten`，只保留亮部；仍需局部染光，不能当无交互素材层。
- 阴影、墨迹、污损：`multiply_dark`，限制在承载面并保留其纹理。
- 色彩、纹理、纸张/胶片质感：低强度 `soft_light_texture`，避免改变人物结构。
- 同机位多张照片、不同对焦或不同照明：先对齐，再用局部蒙版选择每张最有效区域，防止双边重影。

### 溶图边界

- 可以：参考图特效溶入、局部天空/前景、服装纹样、道具、光效素材、同机位不同曝光/焦点融合。
- 转半合成：供体图替换较大地面/中景，但仍保留场馆墙顶与原机位。
- 转大合成：供体图成为完整新世界、人物需要重新摆位/缩放/换机位，或多个场景几何必须重建。

### 溶图验收

- 底图人物身份、姿态、坐标和画布保持。
- 供体只迁移白名单内容，无供体脸、文字、水印和背景泄漏。
- 无双边、鬼影、硬切蒙版、色温断层、锐度断层和重复纹理。
- 透视、尺度、遮挡、接触影、景深、噪点与底图一致。
- 每个供体失败时可单独关闭或只重试其蒙版，不影响其他供体。
