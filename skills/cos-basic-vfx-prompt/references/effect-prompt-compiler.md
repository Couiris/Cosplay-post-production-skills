# 既有特效提示词优化编译器

从 [特效总库](effects-library.md) 选择条目后，不要直接复制“成稿”一句。把条目的形态、材质、融入与负面信息编译成下面的完整效果对象。此规则适用于库内全部既有和新增效果。

## 1. 完整效果对象

```json
{
  "effect_id": "vfx_1",
  "type": "特效族",
  "variant": "具体变体",
  "composition_role": "primary | secondary | atmosphere",
  "hierarchy_weight": 80,
  "source_and_cause": "能量从哪里来、为什么出现",
  "vfx_zone": "语义位置",
  "authorized_area": "可写入像素的最小区域",
  "anchor": "脚点/掌心/武器端点/环境灯源等",
  "depth_order": "behind_subject | around_subject | in_front_of_subject",
  "silhouette_clearance": "脸、手、武器识别点与轮廓留空策略",
  "density_budget": {
    "coverage_percent": 18,
    "focal_exclusion": "面部与关键手势",
    "distribution": "中心集中、边缘稀疏，按深度递减"
  },
  "visual_description": "形态、层次、颜色与单一时间相位",
  "material_emission": {},
  "dynamics": {},
  "environment_interaction": {},
  "camera_response": {},
  "intensity": 60,
  "relight_and_blend": {},
  "anti_sticker": [],
  "acceptance": [],
  "vfx_relight_mask": {}
}
```

非发光效果可将 `material_emission.emissive=false` 并省略 `vfx_relight_mask`；其余字段不可省略。

## 2. 编译顺序

1. **来源**：掌心、武器、脚点、可见灯源、环境裂隙或画外合理来源。没有来源就把效果降为环境氛围，不能凭空黏在人身上。
2. **构图职责**：明确是主效果、辅助效果还是空气层，并写 `hierarchy_weight`（0–100）。默认一个主效果；用户明确要求两个同等叙事中心时允许两个主效果，但要写 `co_dominant_reason`。写人物脸、手势、武器端点和服装识别区的留空策略。
3. **占积与密度预算**：写长宽厚、半径或相对肩宽/身高，并给出覆盖率与分布；强度增加优先增加纵深和环境响应，不均匀铺满画面。
4. **材质分层**：至少写核心、主体、边缘/尾迹三层。火是焰心—火舌—烟烬；电是主干—分叉—电晕；法阵是线芯—能量面—体积辉光。
5. **单一时间相位**：选择“刚点亮/正在扩散/受击瞬间/消散前”等一个瞬间，禁止起始、爆发、余波同时出现。
6. **环境反馈**：写接触、反射、湿润、焦痕、尘雾位移、碎屑受力等真实反应；没有承载面就不要编接触反应。
7. **相机响应**：景深、运动模糊、曝光滚降、色散、炫光、噪点与镜头畸变；同深度效果不能比原片更锐。
8. **光照传播**：自发光效果只照可达面，写亮度上限、衰减和遮挡终止；原主光仍主导。
9. **验收与局部重试**：把最容易失败的 3–6 项改成可见验收条件，并指定最小重试区。

## 3. 按类型补充物理语言

| 类型 | 必须写入 | 常见错误 |
|---|---|---|
| 火焰/爆炸 | 焰心温度梯度、热流上升、烟烬、热扭曲、瞬时照明 | 橙色贴图、火舌朝下、烟火相位矛盾 |
| 冰/晶体/玻璃 | 厚度、折射、内部散射、菲涅尔边、裂纹受力点 | 白色不透明块、无环境折射 |
| 雷电/激光 | 起终点、主干与分叉、局部电晕、击中反馈 | 无来源乱线、均匀描边、穿人体 |
| 水/液体/岩浆 | 重力、黏度、表面张力、反射/折射、润湿边 | 逆重力、塑料液体、无接触 |
| 雾/烟/尘/雪 | 密度梯度、风场、前中后层、遮挡与景深 | 全屏均匀蒙版、等大颗粒 |
| 法阵/符文/界面 | 承载平面、厚度、透视、线芯与能量面、文字策略 | 正圆贴纸、乱码、朝向错误 |
| 翅膀/灵体 | 生根锚点、骨架/羽层或能量结构、人物遮挡、投影 | 多出翅膀、像多肢、根部悬空 |
| 速度/斩击/冲击 | 发力方向、轨迹、受力点、拖尾衰减、单相位 | 方向矛盾、多动作帧 |
| 全息/数字 | 发射源、扫描结构、透明层、像素尺度、环境反射 | UI 贴纸、乱码、屏幕无透视 |
| 镜头内效果 | 可见亮源、光轴、镜片响应、画面空间而非场景空间 | 无来源炫光、全图雾白 |

## 4. 把空泛词改成可观察描述

| 避免单独使用 | 改写方向 |
|---|---|
| “高级感” | 高光滚降、黑位、材质粗糙度、颜色数量、留白 |
| “自然融合” | 遮挡、接触影、反射、透视、景深、颗粒分别写 |
| “电影感” | 光比、色温关系、镜头响应、局部对比和颗粒大小 |
| “超清 8K” | 恢复哪些已有发丝/织纹/刻痕，避免新增假纹理 |
| “炫酷特效” | 具体类型、形态、来源、强度、时间相位和范围 |
| “发光” | 线芯/焰芯、颜色梯度、辉光半径、亮度上限和染光面 |

## 5. 强度不是简单增亮

- 轻：缩小覆盖范围、减少粒子/分叉/层数，保留关键物理反馈。
- 中：完整主形态 + 一项环境反馈 + 一层空气细节。
- 强：优先增加纵深、体积、碎屑和受影响范围；高光仍有细节，脸部仍干净。

不要用全图过曝、全身染色或无限加粒子表示“强”。

## 6. 组合优化

组合效果共享的是**同一叙事瞬间和环境因果**，不强迫共享相同运动方向或同一颜色：

- 每个 effect 单独保留自己的 `dynamics`；例如火焰上升、电流沿刀刃传播可以同时成立。
- `global_moment` 说明所有效果为何在同一快门瞬间出现。
- `palette_relationship` 说明同色、邻近色、冷暖对比或中性色缓冲关系，而不是要求色值相同。
- `shared_environment_response` 说明共同影响的空气、地面、人物和曝光上限，避免重复加光。
- `hierarchy_weight` 决定视觉权重；主效果定义来源与视觉中心。
- 环境响应说明地面/墙面/空气如何被影响。
- 空气层只做深度和运动补充，不抢主体。

若两个效果争夺同一锚点、互相要求不同风向或主光颜色，保留用户优先级更高者，另一个降级为弱辅效果。

当 `effects[]` 多于一个时，在 `vfx_plan` 顶层显式写 `global_moment/palette_relationship/shared_environment_response`，每个 effect 写 `hierarchy_weight`。通常只有一个 `primary`；用户明确要求脚下法阵与武器雷电等双主叙事时可有两个 `primary` 并写 `co_dominant_reason`。空气层不得遮挡脸与关键动作。
