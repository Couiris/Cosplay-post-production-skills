# 素材与材质库（基础后期精简版）

本库服务三件事：①cleanup 补洞时「延续什么材质」；②prop 增材小物/角色特征时「写什么材质、多大、怎么落地」；③特效附着时「表面如何反应」。需要重建整景/铺世界观时改用两个合成技能，本库不做场景生成。

## 1. 尺度合同（人物身高 = 1.0）

增材与补全必须以画面中人物为尺度锚，近大远小服从原片透视，不把示例当硬编码（用鞋底、脚点、已知道具校正）：

| 对象 | 相对身高 | 对象 | 相对身高 |
|---|---|---|---|
| 门高 | 1.1–1.4 | 桌面高度 | 0.35–0.45 |
| 座面/椅面 | 0.22–0.30 | 台阶踢面 | 0.08–0.12 |
| 扶手栏杆 | 0.45–0.55 | 普通水杯 | 0.05–0.07 |
| 书本 | 0.12–0.15 | 手机 | 0.08–0.09 |
| fufu 坐姿公仔 | 0.18–0.25 | 站立小动物(猫/犬) | 0.15–0.30 |
| 皇冠/发饰 | 头高的 0.15–0.4 | 手持武器(剑/杖) | 0.6–1.4 按设定 |
| 兽耳 | 头高 0.15–0.3 | 尾巴 | 体长 0.5–1.2 按设定 |

`scale_contract` 字段写：真实尺寸类别、相对人物倍数、落点、朝向、可见面；低置信度写「逐线匹配原片」，不编数值。

## 2. 材质族描述（补洞 / 增材 / 表面反应通用）

每个材质至少从 `基色 / 粗糙度 / 微纹理 / 边缘 / 新旧 / 干湿 / 透明或反射` 里取适用项描述。**补洞时材质必须与洞口相邻像素同族、同纹理方向、同受光。**

### 石材/砖/地面
青砖、花岗岩、大理石、板岩、砂岩、水磨石、瓷砖、沥青、水泥、碎石路。写：接缝走向、崩角磨损、苔痕、湿润反光、抛光度。补洞关键：砖缝/地砖格线必须跨过洞口连续对齐，透视收束到原灭点。

### 木材
新木、旧木、炭化木、漆木、竹、木地板。写：纹理方向、接榫、磨损、清漆反射。补洞关键：木纹方向延续、地板条沿原走向排列。

### 金属
铁、钢、黄铜、青铜、银、金、铝、钛、镀铬。写：拉丝/铸造/磨砂、氧化锈蚀、指纹、边缘高光（金属高光锐利、随曲面走）。道具增材：金属只在原光源方向出高光，暗部反射环境色。

### 织物（含服装/丝袜/毛绒）
- 常规：棉、麻、丝、缎、绒、纱、呢、皮革、针织。写：经纬织纹、绒向、褶皱张力（保留自然垂坠与动态褶，只去异常堆积）、透光、磨损起球。
- **丝袜专项**：半透明薄织纹，透见下方皮肤与腿型；纵向丝质高光随腿部圆柱面流动；脚踝/膝盖织纹密度升高；后竖线沿腿后正中随透视弯曲；黑丝=半透黑叠肤色、白丝=半透乳白、网袜=规则菱形网孔。
- **毛绒（fufu/兽耳/毛领）**：写绒向（毛顺一个方向倒伏）、长短绒分区、绒尖受光发亮、根部藏阴影、缝线/刺绣、填充饱满度与柔软挤压；毛绒边缘不是光滑线而是细密毛茬。

### 透明体 / 半透体
玻璃、冰、水、树脂、晶体、亚克力、薄纱。写：折射率、厚度、内部杂质/气泡、焦散亮斑、菲涅尔（边缘亮于中心）、对后方景物的透见与扭曲。补洞关键：透明/镜面后的背景要继续画，不能用一块纯色填。

### 地表 / 自然面
沙、雪、泥、草、苔藓、落叶、水洼、灰烬、焦土。写：颗粒尺度、受压痕（脚印/鞋底压痕/草叶压倒/雪凹陷）、湿度、边界过渡。增材落地必给接触压痕。

### 皮肤 / 毛发（人像模块共用）
- 皮肤：保留毛孔、细微绒毛、自然肤色不均；次表面散射（耳尖/鼻翼/指节透光）；T 区/肩/锁骨/肌肉高点出油光泽；哑光区与反光区交错；油润光泽随肌肉骨骼解剖走，不做全身均匀亮膜。
- 毛发：发丝成缕、根根走向、发缝处见头皮但被发丝交错覆盖、高光随发丝束走、毛躁是逆毛的碎茬。
- 血/污：新鲜血=鲜红偏润带高光、半流动；干涸血=褐红哑光结痂；脏污=低饱和颗粒、沿褶皱与凸起边缘分布。

### 科技材质
碳纤维（斜纹编织）、陶瓷涂层、阳极氧化铝、发光玻璃、全息膜、磨砂聚合物、哑光装甲。发光只走结构缝隙/凹槽，配合碳纤维等哑光底材才高级，避免无来源均匀霓虹。

### 能量材质（特效共用，详见 material-light.md）
火、雷、冰、水、圣光、暗能量、符文。写：核心亮度、边缘衰减、体积感、散射、被遮挡终止、对邻近表面的染色。

## 3. cleanup 补洞材质延续速查

| 被移除物所在背景 | 补洞应延续 |
|---|---|
| 纯色/渐变背景布 | 同色同渐变方向，补均匀噪点 |
| 虚化人群/散景 | 同虚化程度的模糊色块与光斑，不补出清晰人脸 |
| 砖墙/瓷砖/格栅 | 砖缝/格线跨洞对齐、透视收束 |
| 木地板/地砖 | 纹理方向与条块排列延续 |
| 草地/树丛/花丛 | 同种类叶片簇、随机朝向、近实远虚 |
| 水面/湿地面 | 反光与涟漪波纹延续，反射方向一致 |
| 天空 | 同方向云的走向与渐变 |
| 栏杆/窗框/梁柱等直线结构 | 直线穿过洞口连续，液化/补洞后不弯 |
| 阴影区 | 延续阴影的软硬与方向，不补出亮斑 |
| 衣物边缘（去安全裤穿帮） | 延续为裙摆内侧暗部阴影或外层丝袜/裙装面料，保持覆盖 |

补洞铁律：**先看洞口四周 5–10px 是什么，就延续什么**；纹理尺度、色温、锐度、噪点、虚化等级全部对齐；直线/格线必须跨洞连续；拿不准材质时补成与周围一致的虚化或暗部，绝不凭空造新物体。

## 5. 数量预算（丰富度）与单件精度

基础后期以克制为美，增材/粒子按下表控量，避免堆满：

| 档位 | 元素预算（默认取轻量–丰富） |
|---|---|
| 克制 1–25 | 1 个元素或稀疏连续材质 |
| 轻量 26–50 | 1 主物或 1 个素材族（**小物默认**） |
| 丰富 51–75 | 1 主物 + 1–2 辅助族，仍留负空间（**特效默认**） |
| 华丽 76–90 | 2–3 个关联素材族，分近中远 |
| 极盛 91–100 | 基础后期不建议，转合成技能 |

`detail_precision`（单件写到多细）与数量分开：小物默认 51–75（接缝、纹理方向、粗糙度、磨损、接触影）；远景物件即使写得细，也要按深度降对比/饱和/锐度。**不得用更多粒子伪装更高精度。**

## 6. 景深五层与颗粒匹配

- foreground 前景：离焦最软、对比低、高光散景大（前景花枝/纱/泡泡必须虚）。
- midground 人物同层：与人物锐度接近；略前后只做渐进轻虚化。
- background 背景：随距离降高频细节/对比/饱和，但保留大结构与灭点，不用模糊掩盖错误。
- airborne 空气粒子：近（大而虚）/中（清晰）/远（小而淡）三组；脸周不成噪点。
- effects 特效：同样有深度，穿人物前后分别匹配焦平面与遮挡；贴地法阵/裂纹沿地面景深，远端更软。
- **颗粒/噪点匹配**：新增像素的噪点颗粒粗细与同深度原片一致；夜景高 ISO 颗粒要带到新增物上，干净棚拍不加颗粒。任何新增物锐度不得高于同深度原内容。

## 7. 接触、承托与投影（增材不悬浮清单）

- 落地物：接触处有接触影（omni 方向、边缘软）+ 表面压痕/反射；硬质物压痕锐利、毛绒/软体有挤压形变。
- 被握持/抱持：写出谁挡住谁（手指挡公仔、公仔挡衣服），承托点受力合理，不悬空。
- 佩戴物（头饰/兽耳/角）：根部藏进发丝、被头发部分遮挡，左右对称、数量正确。
- 悬浮物：必须给理由（法术托举/被抱/绳线），并给与高度相称的淡投影；完全无依托的悬浮只在 vfx 能量体时成立。
- 投影方向统一服从 `subject_light_profile.existing_shadow`；新增物不能比人物投影更硬/更黑。

## 8. 常用增材素材族（按需取，不堆砌）

- 手持/随身：书、卷轴、符纸、扇、伞、灯/灯笼、杯、花束、权杖/剑/弓、手机、玩偶、面具、丝带。
- 角色特征：兽耳、尾巴、精灵耳、犄角、獠牙、翅膀（特效库）、光环（特效库）、纹身咒印、泪痣。
- 前景框景：虚化花枝、薄纱/珠帘、栅栏/窗框、带水珠玻璃、烟雾、前景粒子、垂落藤蔓。
- 地面叙事：落叶、花瓣、水洼倒影、碎砾、法阵（特效库）、台阶、石块、座面、飘落物堆积。
- 空气层：尘、花粉、金粉、星尘、火星、雪晶、水滴、气泡、纸屑、数据碎片——统一主风向、近大远小、匹配快门模糊。
- 组合规则：1 主材质 + 1 对比材质 + 1 点缀；颜色从角色服装取 1 呼应色 + 1 低饱和环境色；文字/徽章/阵营符号只在设定可靠时用，否则抽象几何、不可读，不伪造官方纹章。
