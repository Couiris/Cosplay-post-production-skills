# COS 场景与素材库

按“角色叙事 → 场景母题 → 五层素材 → 材质与光影”组合，不整行照搬。用户指定优先；无明确设定时选一个主母题和最多一个次母题。所有元素都要能回答“为何在这里、如何落地、如何受光”。

## 世界观适配门槛

先建立 `character_worldview_card`：作品/世界观、时代与地域、阵营/组织、职业、能力体系、生活方式、常驻地点、代表材质/颜色/形状、剧情时刻、证据与置信度。

- 每个元素写 `worldbuilding_basis`，至少对应卡片中的一项；只起填空作用且无叙事依据的元素删除。
- 时代技术要一致：古代/奇幻角色不无故出现现代塑料、LED、枪械或工业紧固件；科幻角色不使用无解释的古典魔法符号。
- 地域与组织符号只在可靠时使用；低置信度改用材质、色彩、几何和生活道具暗示，不伪造官方纹章。
- 职业决定功能道具，能力体系决定特效形态，性格决定密度与秩序，剧情时刻决定新旧/破损/天气状态。
- 参考图只提取通用构图、材质、光影和层次，不复制其人物、水印、签名或独特标志。

## 五层丰富度

| richness | 语义 | 元素预算 |
|---:|---|---|
| 0 | 关闭 | 空层 |
| 1–25 | 克制 | 1 个元素或稀疏连续材质 |
| 26–50 | 轻量 | 1 主物或 1 个素材族 |
| 51–75 | 丰富 | 1 主物 + 1–2 辅助族，仍有负空间 |
| 76–90 | 华丽 | 2–3 个相互关联的素材族，分出近中远 |
| 91–100 | 极盛 | 仅大合成；高密度但主体轮廓、脸、手、武器仍无遮挡 |

丰富度控制数量、覆盖率与种类；`detail_precision` 单独控制单件材质精度。不得用更多粒子伪装更高精度。

## 素材精细度

| detail_precision | 必须描述 |
|---:|---|
| 0 | 关闭或只按原片匹配 |
| 1–25 | 类别、主色、大形、画面位置 |
| 26–50 | 实际尺度、朝向、厚度、基础材质、受光面/背光面 |
| 51–75 | 接缝、纹理方向、粗糙度、边缘、磨损/洁净、透明/反射、接触影 |
| 76–90 | 微表面、制造工艺、年代痕迹、局部缺陷、分区反射、表面起伏对投影的影响 |
| 91–100 | 英雄资产级：复合材质层、微小几何、厚度和内部结构、细微积尘/水痕/指纹、镜头与颗粒响应 |

精细度是“生成描述预算”，不是最终可见锐度。远景即使 detail_precision 很高，也要先生成结构正确的资产，再按其深度降低对比、饱和、纹理可见度与锐度。

## 透视、比例、虚化与景深合同

- `perspective_contract`：写出地平线/灭点方向、元素落点、朝向、顶面/底面可见量、贴地单应性和垂直线收敛。证据不足时写“逐线匹配原片”，不编造角度。
- `scale_contract`：人物身高=1.0；门高约 1.1–1.4 个身高、常见桌面约 0.35–0.45 个身高、座面约 0.22–0.30 个身高、台阶踢面约 0.08–0.12 个身高。具体以角色鞋底、姿态和原场景参照校正，不把示例当硬编码。
- `depth_zone`：记录元素相对人物是前、同平面、后近景、远景或极远景；表观大小由真实尺寸、地面落点、焦段与灭点共同决定。
- `focus_blur_contract`：先锁定人物眼睛/面部或用户指定焦点；同一深度素材不得比人物更锐，前后离焦应渐进。虚化包含轮廓扩散、局部对比下降和高光散景变化，不只是统一高斯模糊。
- `atmospheric_perspective`：远景按原片环境降低对比、饱和与细节，冷暖偏移只在已有空气介质合理时出现；近景不套远雾。
- `motion_blur`：只有原片或元素运动支持时添加，方向与速度统一；静止建筑和贴地道具不得用运动模糊掩盖错误。

### 五层虚化关系

- foreground：通常离焦最明显，轮廓较软、局部对比低，高光散景较大；若焦点本来在近景则按原片反转，不能套固定规则。
- midground：人物同平面元素与人物锐度接近；略前/略后元素只做渐进轻虚化，禁止突然糊成一片。
- background：随距离逐步降低高频细节、对比和饱和；仍保留可读的大结构与灭点，不能用模糊掩盖错误建筑。
- airborne：按深度分成近/中/远三组。近处粒子更大且可能虚化，中部粒子较清晰，远处更小、更淡；密度不能在脸周围形成噪点。
- effects：法阵、火焰、雷电、雾、光束等也有深度。穿过人物前后的部分分别匹配对应焦平面与遮挡；贴地法阵沿地面景深变化，远端不应和近端同样锐。
- 同一物体跨越多个深度时允许内部渐变虚化；不得把完整图层一次性统一模糊。

## 素材组合规则

- 一个主材质 + 一个对比材质 + 一个点缀材质，通常比五种同权材质更统一。
- 一个主特效 + 一个环境特效 + 一个空间层次特效；同类粒子不重复。
- 颜色从角色服装/武器提取 1 个呼应色，再选 1 个低饱和环境色；发光色是点缀，不全图灌色。
- 文字、徽章、宗教/阵营符号只有在设定可靠时使用；否则采用抽象几何和不可读小字，禁止伪官方标识。
- 近景负责框景，中景负责叙事，远景负责世界尺度，空中层负责运动方向，地面层负责落地可信度。
