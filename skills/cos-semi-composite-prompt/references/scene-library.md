# 半合成场景元素库

仅在选景或填充元素时读取。每次选一个主场景，最多一个次主题；各层少量取用，不能整行照搬。背景墙和天花板永远属于原景保留区。

每个选中素材都补全：`worldbuilding_basis`、`geometry_and_scale`、`material_surface`、`perspective_contract`、`focus_blur_contract`、`light_and_shadow`。素材丰富度与精细度分别使用 0–100；真实可见细节受其所在景深限制。

## 特别规则

- 房间类：咖啡厅、甜品店、魔法工坊、中式古风房间、欧式贵族房间、图书馆、酒馆旅店、卧室、实验室、医院医务室、哥特教堂和宫殿舞厅只生成部分独立摆件、可移动景片和地板；背景墙、天花板、顶灯、钢架完全不变；远景复杂度默认 off。
- 沙滩：解释为场馆内主题沙滩或滨海展馆布景。人物脚部附近生成压实沙、鞋底/脚点接触凹陷和细沙遮蔽；海面只能是低矮景片，不得以地平线替换远墙；天花板完整保留。
- 水、雪、沙、草和苔藓覆盖整个地面时，仍需保留地面原透视、脚点和承托物几何。局部模式边缘使用自然渐隐或景片边界，不能形成生硬圆形贴片。
- 招牌、书页、御札、屏幕、纹章使用抽象图形或不可读小字，避免乱码、品牌和错误官方标志。
- 色彩从人物服装提取一个呼应色和一个低饱和环境色，仅作用于新增元素。

## 常用素材族

跨场景优先复用这些可控素材族，并按角色和主题替换材质，不凭空增加结构：

- 承托类：矮箱、台阶、石块、座椅、树桩、行李箱、器材箱。必须匹配原承重点高度和脚点，不改人物姿态。
- 框景类：枝叶、帷幔、栏杆、门框景片、灯具边缘、虚化道具。只放画面边角，保持主体轮廓负空间。
- 叙事类：书本、药瓶、工具、乐器、餐具、旅行物、战斗残片、角色能力相关器件。每件写 worldbuilding_basis。
- 地表类：木、石、砖、草、苔、沙、雪、水、金属、树脂。选择局部或全场馆覆盖，并写清过渡边界、纹理方向和接触关系。
- 空气类：尘、雾、烟、雨、雪、花瓣、叶片、纸页、火星、气泡、能量粒子。默认最多两种，统一风向和景深。
- 光效类：已有灯源的光斑、反射、焦散、体积光、轮廓溢光。只能解释原片光线，不新增与人物受光冲突的主光。
