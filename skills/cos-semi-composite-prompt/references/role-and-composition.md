# 角色背景与构图规则

每次使用本技能都读取本文件。目标不是识别角色后堆 IP 符号，而是把角色叙事转译成与原照片兼容的环境线索。

## 角色背景卡

- source：作品/世界观；不确定则写未知，不猜同人设定。
- identity：角色名、时代/地域、种族或组织；只采用用户给出或可靠可见线索。
- role：职业、阵营、社会身份、战斗或生活方式。
- personality：2–4 个与场景有关的性格词，如克制、活泼、疏离、威严、治愈。
- ability_motifs：能力、武器、元素属性、代表材质与符号。
- canonical_places：有把握的常驻地点或剧情场所。
- story_moment：用户希望的剧情阶段或情绪；未指定则采用不改变人物表情的中性时刻。
- evidence/confidence：用户明示、服装道具强线索或弱推断，以及高/中/低置信度。

角色资料只决定环境选择，绝不授权修改人物。无法联网或无法核实时，使用“与角色服装和道具语言相容”的描述，避免声称还原官方地点。

每个新增道具写 `worldbuilding_basis`，至少对应 source / identity / role / personality / ability_motifs / canonical_places / story_moment 中一项。时代技术、地域语汇和组织符号必须一致；低置信度不生成专属徽章、宗教标志、阵营武器或剧情遗物。

## 从角色到场景

1. 叙事必要：解释角色为何在此，如学生对应社团器材，炼金师对应工作台和材料架。
2. 视觉呼应：提取服装/武器已有的 2–3 个颜色、材质或形状作为新增元素点缀；原有人物颜色不改。
3. 性格节奏：活泼用轻盈散点；冷静用秩序线条和留白；威严用轴线、对称和低密度大体块；神秘用遮挡层次与受控暗部。
4. 姿态兼容：站姿强调脚下路径；坐姿提供真实承托面；战斗姿态可用地面冲击痕迹或方向性粒子，但不改变肢体、头发和衣物；半身像减少地面元素。
5. 场馆兼容：顶灯与钢架仍按原状显示；远墙继续作为真实会场边界。新增物以独立景片、低矮摆件、地面覆盖物和空气元素进入，不把原墙/顶棚改造成别的建筑。

## 六区设计

- 地面 ground：连续纹理、接触影、环境遮蔽、反射/湿痕或少量散落物。范围可选人物脚下局部或整个可见场馆地面。
- 前景 foreground：画面边角或镜头近处的 1–3 个虚化框景物；不跨过脸、手、武器、脚点或服装识别区。
- 中景 midground：人物同一深度附近的主题主力，通常 1 个主物加 1–2 个辅物。
- 远景 background：只放低矮、低对比、不覆盖背景墙和天花板的元素；室内房间类默认关闭。
- 原景 retained_original_scene：逐项记录原墙、天花板、顶灯、钢架、未编辑地面和其他保留区域，保留精度最高，不参与生成。
- 浮空 airborne：粒子、花瓣、纸张、火星、尘埃或界面；统一运动方向、尺度和景深，默认不超过两种。

## 原片色彩保护

- locked_original：人物、远墙、天花板、顶部结构和未编辑区域。原材质、色相、饱和度、亮度、白平衡、黑白位、伽马、对比度、色调曲线和高光滚降不变。
- edge_blend_band：人物轮廓外侧窄带，仅去白边、控制溢色和处理透明材质交界；不改人物内部像素。
- generated_regions：新增元素和移除物后的修补区域，只让它们向原片匹配。

禁止用全局 LUT、整体冷暖偏移、整体降饱和或整体提亮来统一氛围。

## 五层丰富度与精度

每个生成层独立使用 0–100：

- richness 0=关闭；1–25=一个稀疏元素；26–50=一个主物或连续材质；51–75=1 主 + 1–2 辅；76–90=多族丰富但保留负空间；91–100 仅在空区充足且不遮挡人物时使用。
- detail_precision 1–25=类别/颜色/大形；26–50=真实尺度/朝向/厚度/基础材质/受光；51–75=接缝/纹理方向/粗糙度/边缘/磨损/透射反射/接触影；76–90=微表面/制造工艺/年代痕迹/分区反射；91–100=英雄资产级复合材质与微小几何，但最终可见锐度仍服从景深。

复杂度控制数量和关系，精度控制单个元素的刻画，二者不得混用。

## 透视、比例和虚化

- 人物身高=1.0，用头宽、肩宽、手掌和脚长交叉校准道具；同深度的门、桌、椅、台阶、地砖和灯具符合真实人体尺度。
- 每层写 `perspective_contract`、`scale_contract` 和 `focus_blur_contract`：落点、灭点、顶/底面可见量、垂直线收敛、相对人物比例、与焦平面的距离、锐度上限和散景。
- foreground 通常更大、更虚；midground 同人物平面时锐度接近；background 随距离降低微对比、饱和和高频细节。以原片为准，原片焦点规则相反时也必须跟随原片。
- airborne 分近/中/远三组；特效跨越人物前后时分别匹配遮挡与虚化，贴地特效沿地面远近渐变，不能整层同样清晰。

## 摄影估计

- 有可靠 EXIF 才写精确焦段和光圈；否则写视觉估计并注明以原片为准。
- 广角约 20–35mm、标准约 35–70mm、中长焦约 70–135mm。
- 光圈必须连同焦平面与虚化描述，例如“视觉近似 f/2.8–4；人物面部与同平面中景清晰，前景明显虚化，远墙柔和但结构可辨”。
- 人物全身、地面清楚时常接近 f/4–5.6 观感；半身且背景奶油化时可近似 f/1.8–2.8；以画面证据为准。
- 匹配原片畸变、边缘拉伸、散景、运动模糊、锐度、噪点与压缩；原片没有的黑边、眩光或浅景深不得新增。
